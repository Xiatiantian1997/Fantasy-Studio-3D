# 开发计划｜先轻量闭环，再完善模型

所有阶段均为**待执行**；列出的是验收条件而非完成状态。

| 阶段 | 工作 | 通过条件 |
| --- | --- | --- |
| 0 设计审查 | Grok 复核基础模型、形变、导出接口、许可 | 意见记录、接口更新、选定候选模型 |
| 1 基础姿势 | 导入可用带 Rig 成年人体、建立 5 姿势、基础相机 | Blender 中动作可复现；几何不明显破面 |
| 2 修正形变 | 审查肩部/腰腹/骨盆腿根等，针对问题修正权重/形态键 | 五姿势正侧斜视角检查合格，失败截图保留 |
| 3 结构导出 | 相同帧、相机和尺寸的 RGB、Depth、Normal、关节投影 | 数据包 schema 合格；图像数值和方向经过人工检查 |
| 4 连接 2D | 在另一个仓库添加结构输入工作流 | 对固定 seed/角色，换姿势可以稳定改变结构 |
| 5 轻量查看器 | 可选 Three.js + GLB | 手机/桌面能旋转缩放和切预设；不强求高级材质原样还原 |

## 里程碑测试

- 基准姿势 + 左右侧身对照：防止坐标轴/镜像错误。
- 双臂上举与坐姿：检查肩部、胸部/胸廓、腹部、臀腿连接。
- 同一相机 RGB/Depth/Normal 叠加：确认像素对齐与方向一致。
- 姿势二维投影：确认投影点落在对应关节，无坐标系颠倒。
- 2D 集成：用同一姿势结构包对比幻真动漫与数字油画，确保改变风格不改变基本姿势。

## 不纳入第一个里程碑

高清皮肤毛孔、内部器官、完整肌肉动力学、布料实时模拟、多人动画、复杂角色游戏引擎、Grok 私人素材管线的自动接入。

## 版本原则

`v0.1` = 文档与 manifest 框架；`v0.2` = 有实际 Blender 导出实验后再命名；`v1.0` = 结构控制图在 2D 端实际通过。
