# 开发计划｜姿势与相机先闭环

所有阶段均为**待执行**，这里只记录验收条件。3D 姿势和**真正的虚拟摄影机取景**是基本能力；服装编辑是未来的小功能，不进入当前开发。

| 阶段 | 工作 | 通过条件 |
| --- | --- | --- |
| 0 设计审查 | 模型、Rig、形变、接口与来源许可 | 明确技术选型和测试样本 |
| 1 基础姿势 | 选可用的成年人体基模（或轻量形体供早期构图），建立站立、侧身、坐姿、举手、跪姿五种姿势与稳定 ID | 在 Blender 中可复现；正侧斜视角轮廓基本合理 |
| 2 姿势修正 | 调整肩部、腰腹、骨盆/腿根等明显问题，检查体型与多角度一致性 | 无严重穿模，姿势能保存、恢复 |
| **3 相机取景（必需）** | **区分观察与摄影模式；构图取景框、镜头位置和朝向、焦距/FOV、透视/正交、画幅比例、正侧斜/俯视/低机位预设** | **锁定姿势调整镜头可重复；导出后人物角度、透视和裁切与取景框一致** |
| 4 结构导出 | 使用几何基准先校准 Depth/Normal 方向和数值，再导出相同相机/尺寸的 RGB、Depth、Normal、Pose 与 manifest | Schema、像素对齐、镜头参数与投影校验通过 |
| 5 联动 2D | 2D 端以兼容工作流消费结构控制包 | 固定画风时改变姿势/相机能够有意义地改变输出 |
| 6 轻量预览 | 按需要增加手机友好的 Three.js + GLB 外观查看层 | 旋转缩放、切姿势与相机机位可用；不用复刻 Blender 全部功能 |
| **以后再做** | **用户上传服装图 → AI 理解并修改预览 → 用户确认 → 简化 3D 贴合 / 交给 2D 参考** | **小功能；初期版型和材质有限；当前不实施** |

## 关键检查

- 观察模式旋转模型不改摄影机；摄影模式调整镜头必然改变 RGB/Depth/Normal/Pose 的一致参考投影。
- 验证透视与正交两种投影、竖横方三类画幅、低机位与俯视机位；防止轴向和镜像错误。
- 同一姿势同一相机，RGB/Depth/Normal 叠加的像素边缘一致；Pose 关节投影位置正确。
- 不能用 AI 生成的“另一个视角”冒充真实几何相机。

## 本阶段不做

医学级软组织、全身高分辨率皮肤、完整肌肉动力学、实时布料仿真、完整 Marvelous Designer 工作流、服装照片一键工业打版、大型材质库、多人动画或复杂游戏引擎。

3D 导出格式仍唯一遵循本仓库 [interface-v0.1.md](interface-v0.1.md)；体验需求见 [ui-plan.md](ui-plan.md)；整体优先级见 [总控 roadmap](https://github.com/Xiatiantian1997/Fantasy-Studio-/blob/main/docs/roadmap.md)。
