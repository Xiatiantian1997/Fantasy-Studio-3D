# 基础模型候选｜先确认可用性，再正式选型

> 这些只是官方来源可核对的候选，不代表已下载安装到用户电脑，也不保证开箱即有高质量 Rig/修正形态键。

## 候选 A：MPFB / MakeHuman Community（优先验证）

- 官方主页：https://www.makehumancommunity.org/mpfb/index.html
- 官方授权说明：https://www.makehumancommunity.org/about/license.html
- 核心人物网格、形态目标、皮肤等官方核心素材：**CC0**；插件代码授权不同，应与模型素材区分；第三方扩展素材另查各自许可。
- 优点：参数化体型，适合开始定义原创成年角色；已有旧人脸研究经验。
- 风险：可能需要权重、关节与软组织形变修正。**先实际测试举手与坐姿**，不要推断默认形变质量足够。

## 候选 B：Blender Studio Human Base Meshes

- 官方资料页：https://www.blender.org/download/demo-files/
- 官方列出 Human Base Meshes v1.4.1，CC0（不同发布版本须复核）。
- 优点：适合从较好的网格拓扑开始。
- 限制：**不要把“Base Meshes”误称为已绑骨、已提供高质量动作的模型**。Rig、蒙皮和姿势能力仍需实测或自行补齐。

## 可选候选 C：第三方预绑定成人角色（尚未选定）

仅在查明模型的真实下载页、明确许可证、绑定结构、权重表现和可编辑程度后纳入候选。尚未核实，不记录虚构名称和地址。

## 选型验收

1. 文件能正常导入 Blender，网格、骨骼、基础形态可编辑。
2. 明确模型和贴图/服装/附加动作的许可与来源。
3. 固定基准体型，在 T/A Pose、举手、坐姿、侧身中检查肩、胸廓、腹部、骨盆及大腿根。
4. 尝试按同一机位渲染对照图，记录拉伸、关节塌陷和穿模。
5. 只有质量满足当前项目目标才开始修正；不要先投入大量雕刻再发现 Rig 不合格。

**暂不选择唯一基础模型**；最终选择以真实 Blender 验收为准。
