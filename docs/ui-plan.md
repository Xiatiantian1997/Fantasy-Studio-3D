# 3D 体验方案｜由总控统一展示

> 这是 **3D 技术模块对总体软件界面的需求**。主界面归 [Fantasy Studio 总控仓库](https://github.com/Xiatiantian1997/Fantasy-Studio-) 管理。本仓库只实现人体网格、Rig、姿势、相机和结构控制图。

## 最终用户体验

打开唯一软件「幻真画室」 → 点 **3D 人体** → 直接看到正常材质的原创成年人体基模。默认不出现复杂骨骼节点、网格线和权重画笔。

| 功能 | 总控界面展示 | 3D 模块提供 |
|---|---|---|
| 人物 | 选成人体基模/体型预设 | 稳定 `subject_id` + 模型 |
| 姿势 | 站立、侧身、坐、举手、跪 | `pose_id` + 骨骼 Action / 相关修正 |
| 视角 | 拖拽旋转、缩放、正侧背视图 | 相机参数与预设 |
| 观察 | 默认实体；可切骨架/线框 | 对应展示层和轻量 GLB |
| 发送 2D | 一键将当前姿势作为绘画参考 | `manifest.json` + RGB / Depth / Normal / Pose |

不强行要求 Three.js 复现 Blender 全部 IK、形态键驱动器与高级材质：第一步在 Blender 里验证模型、姿势和结构导出后再决定预览层如何烘焙。

## 边界

1. 用户不应直接看 ComfyUI 节点或 Blender 的复杂属性面板。
2. 真正的骨架形变调整由 3D 项目自己解决；用户界面只调用已经验收的能力。
3. 导出格式由本仓库 [interface-v0.1.md](interface-v0.1.md) 维护，是 2D/总控共同遵守的唯一数据来源。
4. 3D 未安装、导出不可用时，总控仍应允许独立使用 2D 生图。
5. [旧 body 人脸研究](https://github.com/Xiatiantian1997/body) 保持独立，未经过对接测试前不视为通用人体母版的完整头部。

**状态：仅有界面需求和接口草案。当前无真实全身 GLB 查看器或姿势导出。**
